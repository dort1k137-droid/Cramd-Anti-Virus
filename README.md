# 🛡️ Cramd Anti-Virus

**Современный антивирусный лаунчер с проверкой файлов и мониторингом процессов**

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![.NET](https://img.shields.io/badge/.NET-9.0-purple)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)

## ✨ Возможности

- **🚀 Запуск программ** — встраивание окон приложений внутри лаунчера
- **🔍 Антивирусное сканирование** — проверка файлов перед запуском
  - MD5/SHA256 хеширование
  - Анализ PE-заголовка
  - Проверка цифровой подписи
  - Чёрный список хешей
  - Подозрительные имена и расширения
- **📁 Сканер угроз** — массовое сканирование папок и дисков
- **📊 Мониторинг процессов** — отслеживание памяти и состояния запущенных процессов
- **🎨 Современный UI** — светлая/тёмная тема, Material/Fluent дизайн
- **📝 Подробные логи** — все действия записываются с временными метками

## 📥 Установка

1. Скачайте `ProgramLauncher.exe` из [Releases](https://github.com/YOUR_USERNAME/Cramd-Anti-Virus/releases)
2. Запустите файл (требуется Windows 10/11)
3. .NET runtime **не требуется** — всё включено в один файл

## 🏗️ Сборка из исходников

```bash

dotnet restore
dotnet build

# Публикация в один .exe файл
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o ./publish
```

## 🛡️ Как работает сканирование

1. **Проверка файла** — существование, размер, расширение
2. **Анализ имени** — поиск подозрительных ключевых слов
3. **Вычисление хешей** — MD5 + SHA256
4. **Сверка с чёрным списком** — блокировка известных угроз
5. **PE-анализ** — проверка заголовка, секций, архитектуры
6. **Цифровая подпись** — проверка издателя

Это **учебный проект** для демонстрации возможностей .NET и Win32 API. Не является полноценным антивирусом и не заменяет специализированные решения безопасности.
